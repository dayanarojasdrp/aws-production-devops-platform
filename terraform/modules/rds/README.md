# RDS PostgreSQL module

Creates the platform's stateful database layer:

- a DB subnet group spanning private database subnets;
- a private, encrypted PostgreSQL RDS instance;
- automated backups and environment-specific deletion behavior;
- a Secrets Manager secret containing the database username and generated password.

The password is generated by `random_password` and passed to RDS and the secret version through write-only arguments, so those two resources do not duplicate it in state. The random resource must retain its generated value in Terraform state; the protected remote backend is therefore part of the credential security boundary. The password is never exposed as an output. Increment `credentials_version` deliberately to rotate the generated value, the RDS password, and the stored secret in one apply.

The module does not create an IAM role. It exports `credentials_secret_arn` so the ECS execution role can receive only `secretsmanager:GetSecretValue` for this specific secret.

Run `terraform test` from this directory to validate both the cost-oriented development configuration and the protected production configuration with a mocked AWS provider. The tests do not create AWS resources.
